Observation: # BoringSSL Compilation Instructions

## 1. Prerequisites
*   **CMake**: Version 3.22 or later.
*   **Build System**: Ninja (recommended) or Make (non-Windows).
*   **Compilers**: C11 and C++17 compatible compilers (GCC 6.1+, Clang, or MSVC from Visual Studio 2022+).
*   **Windows Only**: NASM is required. If not found automatically, set `CMAKE_ASM_NASM_COMPILER`.

## 2. Standard Build (Debug)
To build with Ninja:
```bash
cmake -GNinja -B build
ninja -C build
```

To build with Make (non-Windows):
```bash
cmake -B build
make -C build
```

## 3. Release Build
To enable optimizations and disable debug assertions:
```bash
cmake -GNinja -B build -DCMAKE_BUILD_TYPE=Release
ninja -C build
```

## 4. Optional Configurations

### Shared Library
Pass `-DBUILD_SHARED_LIBS=1` to CMake. On Windows, define `BORINGSSL_SHARED_LIBRARY` in code including BoringSSL headers.

### Cross-Compilation (32-bit Intel Example)
```bash
cmake -B build -DCMAKE_TOOLCHAIN_FILE=../util/32-bit-toolchain.cmake -GNinja
```

### Android Build
1.  Export `ANDROID_NDK` to the NDK directory.
2.  Run CMake:
    ```bash
    cmake -DANDROID_ABI=arm64-v8a \
          -DANDROID_PLATFORM=android-21 \
          -DCMAKE_TOOLCHAIN_FILE=${ANDROID_NDK}/build/cmake/android.toolchain.cmake \
          -GNinja -B build
    ```
3.  Build with Ninja.

### iOS Build
Pass the following flags to CMake:
```bash
-DCMAKE_OSX_SYSROOT=iphoneos -DCMAKE_OSX_ARCHITECTURES=ARCH
```
*(Replace `ARCH` with the desired architecture, e.g., `arm64`.)*

### Prefixed Symbols
To avoid symbol conflicts when linking multiple versions:
```bash
cmake -B build -DBORINGSSL_PREFIX=MY_CUSTOM_PREFIX
```

### Binary Size Optimization
To reduce binary size at the cost of performance:
```bash
cmake -B build -DOPENSSL_SMALL=1
```
