- **C Compiler**: `gcc`, `clang`, or another C compiler

## Build Steps (Unix/Linux)

1. **Clone the repository**:
   ```sh
   git clone https://github.com/json-c/json-c.git
   ```

2. **Create and enter a build directory**:
   ```sh
   mkdir json-c-build
   cd json-c-build
   ```

3. **Configure with CMake**:
   ```sh
   cmake ../json-c
   ```
   *Note: You can pass custom options here (see CMake Options below).*

4. **Compile**:
   ```sh
   make
   ```

5. **Install**:
   ```sh
   sudo make install
   ```

## CMake Options
You can customize the build by passing options to `cmake` using `-D`:

| Variable | Type | Description |
| :--- | :--- | :--- |
| `CMAKE_INSTALL_PREFIX` | String | The install location. |
| `CMAKE_BUILD_TYPE` | String | Defaults to "debug". |
| `BUILD_SHARED_LIBS` | Bool | Set to `OFF` to build static library only. |
| `BUILD_STATIC_LIBS` | Bool | Set to `OFF` to build shared library only. |
| `DISABLE_WERROR` | Bool | Set to `ON` to disable treating warnings as errors. |
| `ENABLE_THREADING` | Bool | Set to `ON` to enable partial threading support. |
| `ENABLE_RDRAND` | Bool | Set to `ON` to enable RDRAND Hardware RNG Hash Seed. |

**Example: Build static library only**
```sh
cmake -DBUILD_SHARED_LIBS=OFF ..
```
