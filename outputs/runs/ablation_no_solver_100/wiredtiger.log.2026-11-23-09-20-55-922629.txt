## 1. Prerequisites

### POSIX Systems (Linux, macOS, *BSD)
- **Build Tools**: `git`, `CMake` (3.10.0 or later)

### Windows
- **Build Tools**: `CMake`, Microsoft Visual Studio 2022 (or newer) with C++ compiler
- **Environment**: Use "Visual Studio Developer Command Prompt" or "Developer PowerShell" to ensure VS toolchain environment variables are configured.
- **Optional (Python API)**: 64-bit Python (x86-64)

---

## 2. Build Steps

### A. POSIX Systems (Linux, macOS, *BSD)

1. **Clone the Repository** (if building from source):
   ```bash
   git clone https://github.com/wiredtiger/wiredtiger.git
   cd wiredtiger
   ```

2. **Configure the Build**:
   Create a separate build directory and run CMake:
   ```bash
   mkdir build
   cd build
   cmake ../.
   ```
   *Optional: Use Ninja generator for faster builds:*
   ```bash
   cmake -G Ninja ../.
   ```

3. **Compile**:
   ```bash
   make
   ```
   *Or if using Ninja:*
   ```bash
   ninja
   ```

4. **Install** (Optional):
   ```bash
   make install
   ```
   *Or if using Ninja:*
   ```bash
   ninja install
   ```

### B. Windows

1. **Clone the Repository** (if building from source):
   ```powershell
   git clone https://github.com/wiredtiger/wiredtiger.git
   cd wiredtiger
   ```

2. **Configure the Build**:
   Create a separate build directory and run CMake (use `-A x64` for 64-bit):
   ```powershell
   mkdir build
   cd build
   cmake ..\. -A x64
   ```

3. **Compile**:
   ```powershell
   msbuild ALL_BUILD.vcxproj
   ```

4. **Install** (Optional):
   ```powershell
   msbuild INSTALL.vcxproj
   ```

## 3. Common Configuration Options

You can pass these options to `cmake` during the configuration step:

| Option | Description |
| :--- | :--- |
| `-DENABLE_STATIC=1` | Build only static libraries (default is shared). |
| `-DCMAKE_INSTALL_PREFIX=<path>` | Install libraries/binaries to a custom location. |
| `-DENABLE_PYTHON=1` | Build Python API (requires SWIG). |
| `-DENABLE_LZ4=1` | Enable LZ4 compression support. |
| `-DENABLE_SNAPPY=1` | Enable Snappy compression support. |
| `-DENABLE_ZLIB=1` | Enable Zlib compression support. |
| `-DENABLE_ZSTD=1` | Enable Zstd compression support. |
| `-DCC_OPTIMIZE_LEVEL=<flag>` | Set compiler optimization level (e.g., `-O1`, `-O2`). |
| `-DWT_STANDALONE_BUILD=0` | Disable standalone build (enabled by default). |
