### General Compilation Steps

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ptitSeb/box64
    cd box64
    ```

2.  **Configure and Build:**
    ```bash
    mkdir build; cd build
    cmake .. [OPTIONS]
    make -j4
    ```
    *   Use `make -j1` or `make -j2` if you run out of memory.
    *   Add `-DBAD_SIGNAL=ON` to the cmake command if using a Linux Kernel mixed with Android (e.g., RK3588).

3.  **Install:**
    ```bash
    sudo make install
    ```

4.  **Restart binfmt service (if first install):**
    ```bash
    sudo systemctl restart systemd-binfmt
    ```

### Common Build Options

*   **Enable Box32 (32-bit support):** Add `-DBOX32=ON`.
*   **Enable Box32 binfmt integration:** Add `-DBOX32_BINFMT=ON`.
*   **Enable WowBox64 (experimental):** Add `-DWOW64=ON`.
*   **Enable DynaRec (ARM):** Add `-D ARM_DYNAREC=ON`.
*   **Enable DynaRec (RISC-V):** Add `-D RV64_DYNAREC=ON`.
*   **Enable DynaRec (LoongArch):** Add `-D LARCH64_DYNAREC=ON`.
*   **Include debug info:** Add `-DCMAKE_BUILD_TYPE=RelWithDebInfo`.
*   **Use ccache:** Add `-DUSE_CCACHE=1`.
*   **Static build:** Add `-DSTATICBUILD`.
*   **Build outside git repo:** Add `-DNOGIT=1`.

### Platform-Specific Examples

*   **Generic ARM64 Linux:**
    ```bash
    cmake .. -D ARM_DYNAREC=ON -D CMAKE_BUILD_TYPE=RelWithDebInfo
    ```

*   **Raspberry Pi 5:**
    ```bash
    cmake .. -D RPI5ARM64=1 -D CMAKE_BUILD_TYPE=RelWithDebInfo
    ```
*   **RK3588:**
    ```bash
    cmake .. -D RK3588=1 -D CMAKE_BUILD_TYPE=RelWithDebInfo
    ```
*   **x86_64 Linux:**
    ```bash
    cmake .. -D LD80BITS=1 -D NOALIGN=1 -D CMAKE_BUILD_TYPE=RelWithDebInfo
    ```
*   **RISC-V:**
    ```bash
    cmake .. -D RV64=1 -D CMAKE_BUILD_TYPE=RelWithDebInfo
    ```
*   **LoongArch:**
    ```bash
    cmake .. -D LARCH64=1 -D CMAKE_BUILD_TYPE=RelWithDebInfo
    ```

### Android (Termux/CHRoot)
