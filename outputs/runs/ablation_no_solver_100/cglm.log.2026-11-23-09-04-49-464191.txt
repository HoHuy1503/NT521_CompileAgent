Observation: # cglm Compilation Instructions

cglm can be built using one of the following build systems:

## 1. CMake (All platforms)
```bash
mkdir build
cd build
cmake .. # [Optional] -DCGLM_SHARED=ON
make
sudo make install # [Optional]
```

**Options with defaults:**
- `CGLM_SHARED`: Shared build (ON)
- `CGLM_STATIC`: Static build (OFF)
- `CGLM_USE_C99`: Use C99 instead of C11 (OFF)

**Including in a CMake project:**
- **Header only**: Add `cglm_headers` to `target_link_libraries` and use `add_subdirectory(external/cglm/ EXCLUDE_FROM_ALL)`.
- **Linked**: Add `cglm` to `target_link_libraries` and use `add_subdirectory(external/cglm/)` or `find_package`.

**WebAssembly:**
- Use wasi-sdk or emscripten. Shared build is not supported.
- **WASI SDK**:
  ```bash
  cmake .. \
    -DCMAKE_TOOLCHAIN_FILE=/path/to/wasi-sdk/share/cmake/wasi-sdk.cmake \
    -DWASI_SDK_PREFIX=/path/to/wasi-sdk
  ```
- **Emscripten**:
  ```bash
  emcmake cmake .. \
    -DCMAKE_EXE_LINKER_FLAGS="-s STANDALONE_WASM" \
    -DCGLM_STATIC=ON
  ```

## 2. Meson (All platforms)
```bash
meson build # [Optional] --default-library=static
cd build
ninja
sudo ninja install # [Optional]
```

**Options with defaults:**
- `c_std`: c11
- `buildtype`: release
- `default_library`: shared

**Including in a Meson project:**
```meson
cglm_dep = dependency('cglm', fallback : 'cglm', 'cglm_dep')
executable('exe', 'src/main.c', dependencies : cglm_dep)
```

## 3. Swift (Swift Package Manager)
Add cglm as a dependency in `Package.swift`:
```swift
dependencies: [
    .package(url: "https://github.com/recp/cglm", .branch("master")),
]
```
Add to target dependencies:
```swift
dependencies: [
    .product(name: "cglm", package: "cglm"), // or "cglmc" for compiled version
]
```

## 4. Unix (Autotools)
```bash
sh autogen.sh
./configure
make
[sudo] make install # [Optional]
```
This installs pkg-config files. Use `pkg-config --cflags cglm` and `pkg-config --libs cglm` to retrieve compiler and linker flags.

## 5. Windows (MSBuild)
Navigate to the `win` folder and run:
```powershell
cd win
.\build.bat
```
If `msbuild` fails due to multiple VS versions, use:
```powershell
devenv cglm.sln /Build Release
```
