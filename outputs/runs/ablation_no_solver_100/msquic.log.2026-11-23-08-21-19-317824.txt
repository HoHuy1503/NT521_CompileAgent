Observation: To compile the msquic project, follow these steps:

### 1. Clone the Repository
Clone the repository recursively to include all submodules:
```bash
git clone --recurse-submodules https://github.com/microsoft/msquic.git
```
If you already have the repository, update the submodules:
```bash
git submodule update --init --recursive
```

### 2. Install Dependencies
**Recommended Method (PowerShell):**
1.  **Install PowerShell**: Ensure the latest PowerShell is installed. On Linux (Ubuntu), you can install it via:
    ```bash
    sudo apt-get update
    sudo apt-get install -y wget apt-transport-https software-properties-common
    source /etc/os-release
    wget -q https://packages.microsoft.com/config/ubuntu/$VERSION_ID/packages-microsoft-prod.deb
    sudo dpkg -i packages-microsoft-prod.deb
    rm packages-microsoft-prod.deb
    sudo apt-get update
    sudo apt-get install -y powershell
    ```
2.  **Install .NET SDK**: Install .NET Core 3.1 SDK or newer (e.g., .NET 9 SDK).
3.  **Install CMake**: Ensure CMake 3.20 (Windows) or 3.16 (other platforms) or newer is installed.
4.  **Prepare Machine**: Run the following script to install necessary build dependencies:
    ```powershell
    ./scripts/prepare-machine.ps1
    ```

**Alternative Method (CMake Directly - Linux):**
If building with CMake directly, install the following dependencies:
```bash
sudo apt-add-repository ppa:lttng/stable-2.13
sudo apt-get update
sudo apt-get install cmake build-essential liblttng-ust-dev lttng-tools
```
*Note: For RHEL 8, manually install the latest CMake and run `sudo dnf install openssl-devel libatomic`.*

### 3. Build the Project

**Option A: Using PowerShell (Recommended)**
Run the build script from the project root:
```powershell
./scripts/build.ps1
```
Common configuration options:
*   `-Config <Debug/Release>`: Set build configuration (Default: Debug).
*   `-Arch <x86/x64/arm/arm64>`: Set target architecture (Default: x64).
*   `-Tls <schannel/openssl>`: Select TLS provider (Default: platform-dependent).
*   `-Static`: Build as a static library (Windows only).
*   `-UseExternalOpenSSL`: Link against system OpenSSL (3.5.0+).

Example:
```powershell
./scripts/build.ps1 -Tls openssl -Config Release
```

**Option B: Using CMake Directly**
1.  **Generate Build Files**:
    ```bash
    mkdir build && cd build
    cmake -G 'Unix Makefiles' ..
    ```
    *Note: You must disable logging if building with CMake exclusively, as logging requires .NET Core.*

2.  **Compile**:
    ```bash
    cmake --build .
    ```

### 4. Build Output
*   **PowerShell**: Output is located in the `build` folder, with final binaries in the `artifacts` folder.
*   **CMake**: Output is located in the `build` directory.
