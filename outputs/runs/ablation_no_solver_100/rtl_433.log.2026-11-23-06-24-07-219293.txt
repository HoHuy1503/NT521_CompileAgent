## Prerequisites
- **CMake** (3.13+ recommended)
- **Compiler** (GCC/Clang)
- **Optional but recommended**: RTL-SDR libraries
- **Optional**: SoapySDR libraries
- **Optional**: OpenSSL (for TLS connections)

## Install Dependencies

### Debian/Ubuntu
```bash
sudo apt-get install libtool libusb-1.0-0-dev librtlsdr-dev rtl-sdr build-essential cmake pkg-config
# For TLS support:
sudo apt-get install libssl-dev
```

### CentOS/Fedora/RHEL
```bash
sudo dnf install libtool libusb1-devel rtl-sdr-devel rtl-sdr cmake
# For TLS support:
sudo dnf install openssl-devel
```

### macOS (Homebrew)
```bash
brew install rtl-sdr cmake pkg-config
# For TLS support:
brew install openssl
```

### macOS (MacPorts)
```bash
sudo port install rtl-sdr cmake
# For TLS support:
sudo port install openssl
```

## Build Instructions

### Using CMake + Make
```bash
git clone https://github.com/merbanan/rtl_433.git
cd rtl_433/
cmake -B build
cmake --build build --target install
```

### Using CMake + Ninja (faster)
```bash
git clone https://github.com/merbanan/rtl_433.git
cd rtl_433/
cmake -DFORCE_COLORED_BUILD:BOOL=ON -GNinja -B build
cmake --build build -j 4
cmake --build build --target install
```

### Install to System Prefix
```bash
sudo cmake --build build --target install
```

## CMake Options
- `-DENABLE_RTLSDR=ON|OFF` (default: `ON`)
- `-DENABLE_SOAPYSDR=ON|OFF|AUTO` (default: `AUTO`)
- `-DENABLE_OPENSSL=ON|OFF` (default: auto-detected)
- `-DBUILD_DOCUMENTATION=ON|OFF`
- `-DCMAKE_BUILD_TYPE=Release|Debug`

### Example: Full Configuration
```bash
cmake -DENABLE_RTLSDR=ON -DENABLE_SOAPYSDR=ON -DENABLE_OPENSSL=ON -DBUILD_DOCUMENTATION=OFF -DCMAKE_BUILD_TYPE=Release -GNinja -B build
cmake --build build -j 10
```

## Notes
- For CMake < 3.13, use: `mkdir build && cd build && cmake .. && cmake --build .`
- For CMake ≤ 3.6, add `-DENABLE_OPENSSL=NO` if OpenSSL detection fails
- Ensure consistent SoapySDR versions (0.7 or 0.8) to avoid compilation issues
