**1. Prerequisites**
*   A C compiler (gcc, clang, msvc, etc.)
*   Python (version >= 2.7, including 3.x)
*   `pkg-config` (recommended for detecting external libraries)

**2. Obtain Source Code**
*   **From Git:**
    ```bash
    git clone https://git.aubio.org/aubio
    cd aubio
    ./scripts/get_waf.sh  # Fetches the required waf version
    ```
*   **From Release Tarball:**
    ```bash
    wget https://aubio.org/pub/aubio-<version>.tar.gz
    tar xf aubio-<version>.tar.gz
    cd aubio-<version>
    ```

**3. Configure and Build (C Library)**
Aubio uses `waf` for building.

*   **Configure:**
    ```bash
    ./waf configure
    ```
    *   *Optional Flags:*
        *   `--enable-avcodec`: Enable libav support.
        *   `--enable-sndfile`: Enable libsndfile support.
        *   `--enable-samplerate`: Enable libsamplerate support.
        *   `--enable-fftw3`: Enable FFTW support.
        *   `--enable-double`: Compile in double-precision mode.
        *   `--notests`: Disable running tests during build/install.
        *   `--prefix=/path/to/install`: Set installation directory.

*   **Build:**
    ```bash
    ./waf build
    ```

*   **Install:**
    ```bash
    sudo ./waf install
    ```

**4. Build Python Module**
*   **From Source:**
    ```bash
    ./setup.py build
    sudo ./setup.py install
    ```
    *Or using pip:*
    ```bash
    pip install .
    ```
*   **From PyPI:**
    ```bash
    pip install aubio
    ```

**5. Platform-Specific Notes**
*   **Windows:** Use `waf` instead of `./waf` (e.g., `waf configure build`).
*   **macOS/iOS:** System frameworks (Accelerate, CoreAudio, AudioToolbox) are used automatically. For iOS, configure with `--with-target-platform=ios`.
*   **Linux:** Ensure development libraries for optional features are installed (e.g., `libavcodec-dev`, `libsndfile1-dev`, `libsamplerate0-dev`, `libfftw3-dev`).
