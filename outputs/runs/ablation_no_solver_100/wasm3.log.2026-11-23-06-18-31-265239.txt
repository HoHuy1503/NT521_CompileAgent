## Prerequisites
- **CMake** v3.11 or newer.
- **C99 Compiler**: Clang, GCC, MSVC, MinGW-w64, TinyCC, Zig, or Cosmocc.
- **Python 3** (for tests and extra tools, not required for core build).

## Standard Build (CMake)

### Linux / macOS
**Using Clang:**
```sh
mkdir build
cd build
cmake -GNinja -DCLANG=1 ..
ninja
```
*Note: Use `-DCLANG_SUFFIX="-18"` to specify a versioned Clang (e.g., `clang-18`).*

**Using GCC:**
```sh
mkdir build
cd build
cmake -GNinja ..
ninja
```

**Using TinyCC:**
*Note: TinyCC lacks `stdatomic.h`, so use the simple WASI implementation.*
```sh
mkdir build
cd build
CC=tcc cmake -GNinja -DBUILD_WASI=simple ..
ninja
```

### Windows
If tools are not on `PATH`, check WSL:
```sh
wsl -e bash -lc 'command -v cmake ninja gcc clang python3'
```
If available, build within WSL using the Linux instructions above.

## Direct Compiler Build (No CMake)

**GCC/Clang:**
```sh
gcc -O3 -g0 -s -Isource -Dd_m3HasWASI source/*.c platforms/app/main.c -lm -o wasm3
```

**MinGW-w64 (Windows):**
```sh
x86_64-w64-mingw32-gcc -O3 -g0 -s -Isource -Dd_m3HasWASI source/*.c platforms/app/main.c -lm -lpthread -static -o wasm3.exe
```

## Build for WebAssembly (WASI SDK)

1. Install [WASI SDK](https://github.com/WebAssembly/wasi-sdk).
2. Configure and build:
```sh
export WASI_SDK_PATH=/opt/wasi-sdk

mkdir build-wasi
cd build-wasi
cmake -DCMAKE_TOOLCHAIN_FILE="$WASI_SDK_PATH/share/cmake/wasi-sdk-p1.cmake" \
      -DWASI_SDK_PREFIX="$WASI_SDK_PATH" ..
cmake --build .
```
*Output: `wasm3.wasm` (requires host with tail-call proposal support, e.g., Wasmtime 14+, Node 22+).*

## Build with Zig

1. Install [Zig toolchain](https://ziglang.org/download).
2. Build:
```sh
zig build
```
*Output: `zig-out/bin/wasm3`*

**Options:**
- Release mode: `zig build -Doptimize=ReleaseFast`
- Static library only: `zig build -Dlibm3`
- Cross-compile (e.g., WASI): `zig build -Dtarget=wasm32-wasi`
- Cross-compile (e.g., Apple Silicon): `zig build -Dtarget=aarch64-macos`

## Key Build Options (CMake)

- **WASI Implementation**: `-DBUILD_WASI=none|simple|uvwasi|metawasi` (Default: `uvwasi`; use `simple` for TinyCC).
- **Sanitizer Build**:
  ```sh
  cmake -DCMAKE_BUILD_TYPE=Debug -DBUILD_WASI=simple -DCMAKE_C_FLAGS="-fsanitize=address,undefined" -DCMAKE_EXE_LINKER_FLAGS="-fsanitize=address,undefined" ..
  ```
- **Deterministic Profile**: `-DCMAKE_C_FLAGS="-Dd_m3DeterministicProfile=1"`
- **Guarded Memory**: `-DCMAKE_C_FLAGS="-Dd_m3GuardedMemory=1"` (Requires 64-bit host with MMU).
