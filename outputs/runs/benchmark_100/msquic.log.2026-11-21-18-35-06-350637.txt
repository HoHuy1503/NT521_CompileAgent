
   - **CMake**: Minimum version 3.20 (Windows) or 3.16 (Linux/macOS).
   - **PowerShell**: Recommended for building. Install via package manager if not present.

---

## Method 1: Building with PowerShell (Recommended)

### 1. Prepare the Machine
Run the following script to install necessary dependencies:
```powershell
./scripts/prepare-machine.ps1
```

### 2. Build the Project
Execute the build script:
```powershell
./scripts/build.ps1
```

### Common Build Options
- **Configuration**: `-Config <Debug/Release>` (Default: Debug)
- **Architecture**: `-Arch <x86/x64/arm/arm64>` (Default: x64)
- **TLS Provider**: `-Tls <schannel/openssl>` (Default: Platform-dependent)
  - *Note*: `schannel` requires Windows Server 2022+. Use `-Tls openssl` for Linux or older Windows.
- **Static Library**: `-Static` (Windows only)
- **External OpenSSL**: `-UseExternalOpenSSL` (Requires OpenSSL 3.5.0+)
- **Clean Build**: `-Clean`

**Example**: Build with OpenSSL on Linux:
```powershell
./scripts/build.ps1 -Tls openssl
```

### Build Output
- Intermediate files: `build/`
- Final binaries: `artifacts/`

---

## Method 2: Building with CMake (Direct)

*Note: This method requires disabling logging and is less frequently updated than the PowerShell method.*

### 1. Install Dependencies (Linux Example)
```bash
sudo apt-add-repository ppa:lttng/stable-2.13
sudo apt-get update
sudo apt-get install cmake build-essential liblttng-ust-dev lttng-tools
```

### 2. Generate Build Files
```bash
mkdir build && cd build
cmake -G 'Unix Makefiles' ..
```

### 3. Build
```bash
cmake --build .
```
