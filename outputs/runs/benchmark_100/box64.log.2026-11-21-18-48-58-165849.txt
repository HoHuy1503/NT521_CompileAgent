## 1. Prerequisites

   ```bash
   git clone https://github.com/ptitSeb/box64
   cd box64
   ```

2. **Create and enter the build directory:**
   ```bash
   mkdir build
   cd build
   ```

3. **Configure with CMake:**
   ```bash
   cmake .. [OPTIONS]
   ```
   *Replace `[OPTIONS]` with the specific flags for your target platform (see Section 3).*

4. **Compile:**
   ```bash
   make -j4
   ```
   *Note: Use `-j1` or `-j2` if you encounter memory issues.*

5. **Install:**
   ```bash
   sudo make install
   ```

6. **Restart binfmt service (Linux with systemd):**
