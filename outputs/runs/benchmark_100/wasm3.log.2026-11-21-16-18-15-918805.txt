Observation: # Wasm3 Compilation Instructions

## Prerequisites
- **CMake** v3.11 or newer.
- **C99 Compiler**: Clang, GCC, MSVC, MinGW-w64, TinyCC, Zig, or Cosmocc.
- **Python 3**: Required for extra tools (not strictly needed for core compilation).

## 1. Build with CMake (Linux, OS X)

### Using Clang
```sh
mkdir build
cd build
cmake -GNinja -DCLANG=1 ..
ninja
```
*Note: Use `-DCLANG_SUFFIX="-18"` to specify a versioned Clang (e.g., `clang-18`).*

### Using GCC
```sh
mkdir build
cd build
cmake -GNinja ..
ninja
```

### Using TinyCC
*Note: TinyCC lacks `stdatomic.h`, so use the simple WASI implementation.*
```sh
mkdir build
cd build
CC=tcc cmake -GNinja -DBUILD_WASI=simple ..
ninja
```

## 2. Build with Zig

Install the latest [Zig toolchain](https://ziglang.org/download), then run:

```sh
zig build
```
*   **Release Build**: `zig build -Doptimize=ReleaseFast`
*   **Static Library Only**: `zig build -Dlibm3`
*   **Cross-compile (e.g., WASI)**: `zig build -Dtarget=wasm32-wasi`
*   **Cross-compile (e.g., Apple Silicon)**: `zig build -Dtarget=aarch64-macos`

## 3. Build for WebAssembly (WASI SDK)

Requires the [WASI SDK](https://github.com/WebAssembly/wasi-sdk).

```sh
export WASI_SDK_PATH=/opt/wasi-sdk

mkdir build-wasi
cd build-wasi
cmake -DCMAKE_TOOLCHAIN_FILE="$WASI_SDK_PATH/share/cmake/wasi-sdk-p1.cmake" \
      -DWASI_SDK_PREFIX="$WASI_SDK_PATH" ..
cmake --build .
```
*Note: The resulting `wasm3.wasm` requires a host with tail-call support (Wasmtime 14+, Node 22+, or Wasm3 0.9.0+).*

## 4. Direct Compiler Build (Quick/Cross-compilation)

Useful when build systems are unavailable.

```sh
gcc -O3 -g0 -s -Isource -Dd_m3HasWASI source/*.c platforms/app/main.c -lm -o wasm3
```

## 5. Build Options

Configure options via CMake flags, defined in `source/m3_config.h`:

```sh
cmake -DCMAKE_C_FLAGS="-Dd_m3DeterministicProfile=1" ..
```

Key options:
- `d_m3GuardedMemory`: Uses 8GiB reserved address space for bounds checking (requires 64-bit host with MMU).
- `d_m3DeterministicProfile`: Ensures deterministic execution (normalizes NaN, uses runtime for clocks/entropy).
- `d_m3HasThreadStackProbe`: Queries OS for actual thread stack size.
- `d_m3HasAtomics`: Implements atomic instructions for the threads proposal.
