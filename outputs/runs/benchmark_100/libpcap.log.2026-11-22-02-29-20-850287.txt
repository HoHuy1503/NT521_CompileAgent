**Method 1: Build with Autotools (configure/make)**
1.  **Generate Configure Script (if building from git clone):**
    *   Run `./autogen.sh`.
    *   *Note:* On Linux 32-bit systems with Autoconf >= 2.72 and glibc >= 2.34, run `export BUILD_YEAR2038=yes` before `./autogen.sh` for Y2038-safe builds.
    *   *Note:* If a specific `autoreconf` version is needed, use `AUTORECONF=autoreconf-2.69 ./autogen.sh`.
2.  **Configure:**
    *   Run `./configure`. Use `./configure --help` to view available options.
    *   *Optional:* Override packet capture type with `--with-pcap=<type>` if auto-detection fails.
3.  **Build:**
    *   Run `make`.
    *   *Note:* On OpenBSD, you may need to run `AUTOCONF_VERSION=2.69 make`.
4.  **Install (Optional):**
    *   Run `sudo make install` (requires root privileges).

**Method 2: Build with CMake**
1.  **Create Build Directory:**
    *   Create a separate directory for build files (e.g., `mkdir build && cd build`).
2.  **Configure:**
    *   Run `cmake <path-to-source-directory>`.
    *   Use `-G` to select the generator and `-D` flags for configuration options.
    *   *Optional:* Override packet capture type with `-DPCAP_TYPE=<type>`.
3.  **Build:**
    *   Run the build tool (e.g., `make` or `cmake --build .`).
4.  **Install (Optional):**
    *   Run the build tool with the `install` target (e.g., `sudo make install`).

**Important Notes:**
*   **Do not run the build as root.** This can cause permission issues in the build directory.
*   If the build system reports "cannot determine packet capture interface," your system may not support packet capture, or libpcap may not support your specific interface type.
*   An `uninstall` target is supported for both build methods.
