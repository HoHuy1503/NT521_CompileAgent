        ```bash
        cmake .. -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF
        ```
    *   To specify a custom **installation prefix** (e.g., to avoid system directories):
        ```bash
        cmake .. -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=$HOME/local/gmssl
        ```
    *   To enable **hardware optimizations** (e.g., AVX2, ARM64, AES-NI), add specific flags such as:
        ```bash
        cmake .. -DENABLE_SM4_AVX2=ON -DENABLE_SM2_AMD64=ON
        ```

3.  **Compile the Project**:
    ```bash
    cmake --build .
    ```

4.  **Install the Project**:
    ```bash
    sudo cmake --install .
    ```
    *   **Default Install Paths**:
