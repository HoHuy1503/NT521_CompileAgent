Observation: # MsQuic Compilation Instructions

## Prerequisites
1. **Clone the Repository**:
   ```bash
   git clone --recurse-submodules https://github.com/microsoft/msquic.git
   ```
   *For existing repositories, run:*
   ```bash
   git submodule update --init --recursive
   ```

2. **Install Dependencies**:
   - **.NET SDK**: Install .NET Core 3.1 SDK or newer (e.g., .NET 9 SDK).
   - **CMake**: Minimum version 3.20 (Windows) or 3.16 (other platforms).
   - **PowerShell** (Recommended): Install the latest PowerShell for cross-platform build scripts.
     - *Ubuntu Installation*:
       ```bash
       sudo apt-get update
       sudo apt-get install -y wget apt-transport-https software-properties-common
       source /etc/os-release
       wget -q https://packages.microsoft.com/config/ubuntu/$VERSION_ID/packages-microsoft-prod.deb
       sudo dpkg -i packages-microsoft-prod.deb
       rm packages-microsoft-prod.deb
       sudo apt-get update
       sudo apt-get install -y powershell
       ```

## Method 1: Building with PowerShell (Recommended)

1. **Prepare the Machine** (First-time build):
   ```powershell
   ./scripts/prepare-machine.ps1
   ```

2. **Run the Build**:
   ```powershell
   ./scripts/build.ps1
   ```

3. **Optional Configuration**:
   - **TLS Provider**: Use OpenSSL if `schannel` is not available (e.g., on Linux or older Windows):
     ```powershell
     ./scripts/build.ps1 -Tls openssl
     ```
   - **External OpenSSL**: Link against system OpenSSL (3.5.0+):
     ```powershell
     ./scripts/build.ps1 -Tls openssl -UseExternalOpenSSL
     ```
   - **Configuration**:
     - `-Config <Debug/Release>`: Default is `Debug`.
     - `-Arch <x86/x64/arm/arm64>`: Default is `x64`.
     - `-Static`: Compile as a static library (Windows only).
     - `-Clean`: Force a clean build.

4. **Build Output**:
   - Intermediate files: `build/` folder.
   - Final binaries: `artifacts/` folder (organized by platform/architecture/TLS).

## Method 2: Building with CMake (Alternative)

*Note: This method requires disabling logging and is less frequently updated than the PowerShell method.*

1. **Install Linux Dependencies** (if applicable):
   ```bash
   sudo apt-add-repository ppa:lttng/stable-2.13
   sudo apt-get update
   sudo apt-get install cmake build-essential liblttng-ust-dev lttng-tools
   ```

2. **Generate Build Files**:
   ```bash
   mkdir build && cd build
   cmake -G 'Unix Makefiles' ..
   ```

3. **Compile**:
   ```bash
   cmake --build .
   ```
