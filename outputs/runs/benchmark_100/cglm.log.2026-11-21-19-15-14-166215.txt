Observation: # cglm Compilation Instructions

cglm can be built using the following build systems:

## 1. CMake (All Platforms)
```bash
mkdir build
cd build
cmake .. # Optional: -DCGLM_SHARED=ON
make
sudo make install # Optional
```

**Key Options:**
- `CGLM_SHARED`: Shared build (default: ON)
- `CGLM_STATIC`: Static build (default: OFF)
- `CGLM_USE_C99`: Use C99 instead of C11 (default: OFF)

## 2. Meson (All Platforms)
```bash
meson build # Optional: --default-library=static
cd build
ninja
sudo ninja install # Optional
```

**Key Options:**
- `c_std`: C standard (default: c11)
- `buildtype`: Build type (default: release)
- `default_library`: Library type (default: shared)

## 3. Autotools (Unix)
```bash
sh autogen.sh
./configure
make
[sudo] make install # Optional
```
This installs pkg-config files for integration with other projects.

## 4. MSBuild (Windows)
Navigate to the `win` directory and run:
```powershell
cd win
.\build.bat
```
Alternatively, if `msbuild` fails due to multiple Visual Studio versions:
```powershell
devenv cglm.sln /Build Release
```

## 5. Swift Package Manager
Add cglm as a dependency in your `Package.swift`:
```swift
dependencies: [
    .package(url: "https://github.com/recp/cglm", .branch("master")),
]
```
Then add the product to your target:
```swift
dependencies: [
    .product(name: "cglm", package: "cglm"), // For static/inlined
    // or
    .product(name: "cglmc", package: "cglm"), // For compiled version
]
```
