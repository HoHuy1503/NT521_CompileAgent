Observation: # Redis Compilation Instructions

## 1. Prerequisites
- **Standard Build**: Ensure you have a C compiler (gcc or clang) and make installed.
- **32-bit Build (Optional)**: Install 32-bit libraries if targeting 32-bit binaries:
  ```sh
  sudo apt-get install gcc-multilib g++-multilib
  ```
- **TLS Support (Optional)**: Ensure OpenSSL development libraries are installed if building with TLS.

## 2. Basic Compilation
Navigate to the Redis source directory and run:
```sh
make
```

## 3. Advanced Build Options
You can customize the build by passing specific variables to `make`:

### TLS Support
To build with TLS support:
```sh
make BUILD_TLS=yes
```

### Memory Allocator
Redis uses `jemalloc` by default. To use the system allocator:
```sh
make MALLOC=libc
```
Or explicitly specify jemalloc:
```sh
make MALLOC=jemalloc
```

### Compilers and Flags
- **C Compiler**:
  ```sh
  make CC=clang
  ```
- **C++ Compiler**:
  ```sh
  make CXX=clang++
  ```
- **C Flags**:
  ```sh
  make CFLAGS="-O2 -g"
  ```
- **C++ Flags**:
  ```sh
  make CXXFLAGS="-O2 -g"
  ```
- **Linker Flags**:
  ```sh
  make LDFLAGS="-Wl,-rpath,..."
  ```
- **Optimization Level**:
  ```sh
  make OPTIMIZATION=-O2
  ```
- **Debug Level**:
  ```sh
  make DEBUG=-g
  ```

### Sanitizers
- **AddressSanitizer**:
  ```sh
  make SANITIZER=address
  ```
- **UndefinedBehaviorSanitizer**:
  ```sh
  make SANITIZER=undefined
  ```

### Verbose and Warning Options
- **Verbose Output**:
  ```sh
  make V=1
  ```
- **Enable Warnings**:
  ```sh
  make WARN=1
  ```
- **Treat Warnings as Errors**:
  ```sh
  make WARN_ERROR=1
  ```

## 4. 32-bit Binary Compilation
To build 32-bit binaries, ensure 32-bit libraries are installed and use:
```sh
make CFLAGS="-m32" LDFLAGS="-m32"
```
